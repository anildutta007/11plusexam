# 11+ Compass (UK Grammar School Guide & Postcode Explorer)

An all-in-one web platform designed to inform and reassure UK parents navigating the 11-plus grammar school admission process.

---

## 🌟 Key Features

1. **Interactive Postcode & Catchment Finder**:
   - Real-time geocoding via UK's `api.postcodes.io`.
   - Accurate straight-line distance calculations (Haversine formula).
   - Radius comparison against school-specific priority circles.
   - Clear indicators for *Inside Catchment*, *Outside Catchment*, or *Superselective (Score Rank)*.

2. **Grammar School Intelligence & Cut-Off Scores**:
   - Comprehensive profiles for selective schools across Greater London (Sutton, Barnet, Kingston, Bexley), Buckinghamshire, Essex, Kent, West Midlands/Birmingham, and Greater Manchester (Trafford).
   - Seats vs. Applicants (competition ratios).
   - Historical admitted cut-off scores (e.g. Bucks STTS 121, Bexley Selection Score, CSSE ~352+, Trafford 334+).
   - Progress 8, Attainment 8, and Ofsted ratings.

3. **Catchment Housing & Rental Benchmarks**:
   - Average purchase prices for 2-bed, 3-bed, and 4-bed homes.
   - Average monthly rental rates.
   - Essential warnings on local authority anti-fraud residency rules and tenancy requirements.

4. **11+ Exam 101 & 12-Month Preparation Roadmap**:
   - Breakdown of English, Maths, Verbal Reasoning (VR), and Non-Verbal/Spatial Reasoning (NVR).
   - Practical, child-centred study habits avoiding exhaustion and burnout.

5. **Psychology of 11+ & Handling Non-Qualification**:
   - Recognizing hidden anxiety and stress signals.
   - Scripted guidance for parents on what to say (and what *never* to say) on results day.
   - Demystifying grammar myths and celebrating secondary modern / comprehensive pathways.

6. **Sample Exam Papers & Resources**:
   - Official sample materials across GL Assessment, CSSE, Sutton SET, and Kent tests.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 19)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Geocoding API**: [Postcodes.io](https://postcodes.io/)

## 🚀 Getting Started

1. Clone repository:
   ```bash
   git clone https://github.com/anildutta007/11plusexam.git
   cd 11plusexam
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
